# Overview

Visao geral funcional do `praxis-metadata-starter` dentro da **Praxis Platform** — uma plataforma semanticamente orientada para aplicacoes corporativas AI-native, em que recursos, regras, acoes, dados e politicas sao descritos uma vez e operados por interfaces tradicionais, interfaces generativas, agentes de IA e integracoes.

Use esta area quando voce quiser entender rapidamente o papel do starter na
plataforma antes de entrar nos guias detalhados.
