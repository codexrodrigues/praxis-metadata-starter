Stats Multi-Metric Examples

Scope

This document records the additive contract extension introduced for praxis.stats multi-metric requests in group-by and timeseries.

In this phase:

  • metric remains valid and fully supported
  • metrics[] is now part of the public contract for group-by and timeseries
  • DISTINCT_COUNT is part of the public metric operation set and requires a governed field
  • value remains the compatibility field for the primary metric
  • values is the compatibility-safe container for per-alias values
  • group-by and timeseries already execute this shape in the starter JPA runtime
  • distribution remains mono-metric until the executor is expanded

Group-By Request

{
  "filter": {
    "status": "ATIVO"
  },
  "field": "departamentoId",
  "metrics": [
    {
      "operation": "COUNT",
      "alias": "total"
    },
    {
      "operation": "SUM",
      "field": "massaLiquida",
      "alias": "massaLiquida"
    },
    {
      "operation": "DISTINCT_COUNT",
      "field": "perfilFolha",
      "alias": "perfis"
    }
  ],
  "limit": 10,
  "orderBy": "VALUE_DESC"
}

Group-By Response

{
  "field": "departamentoId",
  "metric": {
    "operation": "COUNT",
    "alias": "total"
  },
  "metrics": [
    {
      "operation": "COUNT",
      "alias": "total"
    },
    {
      "operation": "SUM",

      "alias": "massaLiquida"
    },
    {
      "operation": "DISTINCT_COUNT",

}

Multi-Dimensional Cross-Tab (2D) & Temporal Extractions in group-by

POST /{resource}/stats/group-by also supports dimensions[] (up to maxDimensions, default 2), canonical dimension extractions (NONE, cyclic HOUR_OF_DAY, DAY_OF_WEEK, DAY_OF_MONTH, MONTH_OF_YEAR, QUARTER_OF_YEAR, and linear HOUR, DAY, WEEK, MONTH, QUARTER, YEAR), timezone, periodPreset / from / to, fillGaps, and AVG_PER_CYCLE_OCCURRENCE.

Request (2D Cyclic Operational Rhythm 7 × 24 = 168)

{
  "filter": {
    "status": "ATIVO"
  },
  "dimensions": [
    {
      "field": "lastCheckInAt",
      "extraction": "DAY_OF_WEEK",
      "alias": "weekday"
    },
    {
      "field": "lastCheckInAt",
      "extraction": "HOUR_OF_DAY",
      "alias": "hour"
    }
  ],
  "timezone": "America/Sao_Paulo",
  "periodPreset": "LAST_30_DAYS",
  "fillGaps": true,
  "limit": 168,
  "metrics": [
    {
      "operation": "COUNT",
      "alias": "count"
    },
    {
      "operation": "AVG_PER_CYCLE_OCCURRENCE",
      "alias": "avgCountPerSlot"
    }
  ],
  "orderBy": "KEY_ASC"
}

Response

{
  "field": "lastCheckInAt",
  "dimensions": [
    {
      "field": "lastCheckInAt",
      "extraction": "DAY_OF_WEEK",
      "alias": "weekday"

    {
      "field": "lastCheckInAt",

      "alias": "hour"

  ],
