Praxis Metadata Starter

Biblioteca canônica da plataforma Praxis para publicar contratos metadata-driven no backend Spring Boot. O starter enriquece o OpenAPI com x-ui, expõe superfícies estruturais (/schemas/filtered) e semânticas (/schemas/domain, /schemas/surfaces, /schemas/actions, /{resource}/capabilities), empacota o Praxis Cockpit (/praxis/cockpit) e fornece infraestrutura base para recursos REST, filtros JPA, option sources, estatísticas, exportação de coleções e consumo por runtimes Angular e agentes de IA.

O que este starter entrega

  • Hierarquia canônica resource-oriented (AbstractResourceController, AbstractReadOnlyResourceController, AbstractBaseResourceService, ResourceMapper).
  • Contrato estrutural enriquecido com x-ui via /schemas/filtered com ETag e X-Schema-Hash.
  • Descoberta semântica e governança para IA: /schemas/catalog, /schemas/domain, /schemas/surfaces, /schemas/actions e /{resource}/capabilities.
  • Filtros dinâmicos com @Filterable, lookups governados com OptionSourceRegistry, analytics (/{resource}/stats/*) e exportação de coleções (POST /{resource}/export).
  • Cockpit automático do host em GET /praxis/cockpit e respostas padronizadas em RestApiResponse com Spring HATEOAS (_links).

Como começar

<dependency>
  <groupId>io.github.codexrodrigues</groupId>
  <artifactId>praxis-metadata-starter</artifactId>
  <version>8.0.0-rc.174</version>
</dependency>

Depois, anote seus DTOs separados com @Schema, @UISchema e @DomainGovernance, exponha controllers com @ApiResource(value = ..., resourceKey = ...) e siga os guias publicados no GitHub Pages.
