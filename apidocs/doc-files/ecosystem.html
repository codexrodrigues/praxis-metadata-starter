Ecossistema Praxis — Módulos e Fronteiras

Conheça os repositórios oficiais que compõem a plataforma Praxis e como eles se conectam ao praxis-metadata-starter.

Praxis Config Starter (Spring Boot)

Repositório: codexrodrigues/praxis-config-starter

Fronteira canônica para persistência de configurações de UI (ui_user_config), ai_registry, api_metadata, regras de domínio e authoring governado por IA em /api/praxis/config/** e /api/praxis/runtime/**.

Praxis API Quickstart (Host Operacional de Referência)

Repositório: codexrodrigues/praxis-api-quickstart · Demo: Praxis Cockpit ao vivo

Aplicação Spring Boot + PostgreSQL de referência que integra praxis-metadata-starter e praxis-config-starter, demonstrando recursos reais, surfaces, workflow actions, analytics, option sources e governança de domínio.

Runtime Angular Oficial (@praxisui/*)

Repositório: codexrodrigues/praxis-ui-angular · Site oficial: praxisui.dev

Superfície pública das bibliotecas @praxisui/* para consumo de /schemas/filtered, /{resource}/capabilities e do vocabulário x-ui em tempo de execução.

Seed de Backend

Repositório: codexrodrigues/praxis-backend-seed-app

Projeto inicial Spring Boot + Praxis com estrutura limpa para iniciar um novo microserviço do zero.

Node.js / TypeScript & Gerador x-ui

Repositórios: praxis-node · praxis-openapi-ui-schema-generator

Ferramentas complementares para integrar aplicações Node.js e pipelines de geração de artefatos JSON no vocabulário x-ui.
